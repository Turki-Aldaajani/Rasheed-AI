# البنية المعمارية — تدفق البيانات

نظرة سريعة على كيف تتحرك البيانات داخل رشيد، لمن يبدأ المساهمة لأول مرة. لهيكلة المجلدات الكاملة راجع [README](../README.md#البنية).

## حالة التطبيق (State Machine)

يدير `AppShell` مرحلة واحدة فقط للتطبيق كامل، بدون مكتبة إدارة حالة خارجية:

```mermaid
flowchart LR
    landing[الواجهة] -->|حلل فاتورتك| upload[رفع الفاتورة]
    landing -->|نموذج تجريبي| analyzing
    upload -->|حلل| analyzing[التحليل]
    analyzing --> dashboard[لوحة النتائج]
    dashboard -->|إعادة البدء| landing
```

## مساران للبيانات

المشروع الآن فيه مساران يغذّيان الواجهة، وهذا مهم يفهمه أي مساهم جديد:

```mermaid
flowchart LR
    subgraph محاكاة["مسار المحاكاة (حتمي)"]
        data["data/*.ts<br/>بيانات تجريبية ثابتة"] --> sim["lib/simulation.ts<br/>حسابات التبريد والتعرفة والتوفير"]
    end
    subgraph رفع["مسار الرفع الفعلي"]
        upload["UploadScreen"] --> bill["lib/billService.ts<br/>تحقق + ضغط الصورة"]
        bill --> storage["lib/storage.ts + supabaseClient.ts<br/>تخزين Supabase"]
        storage --> table[("جدول bills")]
    end
    sim --> ui["components/**"]
    table --> ui
```

- **مسار المحاكاة**: `data/` بيانات تجريبية ثابتة → `lib/simulation.ts` يحسب كل الأرقام (التبريد، تسخين المياه، الفاتورة) في مكان واحد → المكوّنات تعرض النتيجة فقط. هذا المسار يغذّي حاليًا خطة رشيد ومحاكي «ماذا لو؟» وقسم المياه.
- **مسار الرفع الفعلي**: `UploadScreen` يرفع الملف عبر `lib/billService.ts` (تحقق من النوع والحجم، ثم ضغط الصورة) إلى Supabase Storage عبر `lib/storage.ts`، ثم تُحفظ بيانات الفاتورة في جدول `bills`. `Overview` يقرأ أحدث فاتورة من نفس الجدول عند تحميل الصفحة.

قاعدة صارمة على المسارين: **لا قيم مكتوبة داخل الواجهات**. أي رقم جديد يمر عبر `data/` أو قاعدة البيانات، لا عبر ثوابت داخل مكوّن React.

## ماذا يتغيّر لاحقًا؟

هذه الطبقات مصمّمة لتُستبدل دون كسر الواجهات — راجع [Issues المستودع](https://github.com/Turki-Aldaajani/Rasheed-AI/issues) لتفاصيل كل مهمة ومعيار قبولها:

| الآن | لاحقًا |
| --- | --- |
| رفع وتخزين فعلي في Supabase، بدون قراءة ذكية للفاتورة | استخراج بيانات الفاتورة فعليًا عبر Gemini Vision |
| أرقام تعرفة وطقس ثابتة في `lib/simulation.ts` | Function Calling للتعرفة الرسمية والطقس الفعلي |
| لا مصادقة مستخدمين | Supabase Auth وربط الفواتير بحساب المستخدم |
