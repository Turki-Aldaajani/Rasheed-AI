# رشيد (Rasheed AI)

مساعد ذكي قائم على الذكاء الاصطناعي التوليدي لترشيد استهلاك الطاقة والمياه في المنازل السعودية.

## نبذة عن المشروع

يعتمد المشروع على تقنية **Gemini Vision** لقراءة وتحليل صور الفواتير والعدادات الذكية فورياً، وربطها بالبيانات المحلية لدرجات الحرارة وتعرفة الكهرباء والمياه الرسمية عبر استدعاء الوظائف (**Function Calling**).

يقدم النظام للمستخدم:

- تحليلاً دقيقاً لأنماط الاستهلاك
- خطة تشغيلية مخصصة للأجهزة والمكيفات والأدوات الصحية
- محاكاة مالية توضح قيمة الفاتورة المتوقعة ونسبة التوفير المالي بالريال السعودي بعد تطبيق التوصيات

## التقنيات المستخدمة

- Gemini Vision
- Function Calling
